# DSim Cheats Menu
A cheats menu mod for the game DEEEER Simulator.
### Requirements
- [BepInEx](https://github.com/bepinex/bepinex) (Mod loader)
- [BepInEx ConfigurationManager](https://github.com/BepInEx/BepInEx.ConfigurationManager) (In-game config menu)
### Installation
Make sure you have finished setting up BepInEx for your game before following these steps. You can find the guide on how to install BepInEx [here](https://docs.bepinex.dev/articles/user_guide/installation/index.html). And remember to install BepInEx ConfigurationManager as well.
1. Run the game after installing BepInEx to initialize all the essential files and folders
2. Download the `.dll` file of the mod [here](https://github.com/Studumb/DSim-Cheats-Menu/releases/latest)
3. Locate your game folder, in your game folder go to `BepInEx` -> `plugins` and move the `.dll` file into this folder
    - Note: You can locate your game folder from Steam App
4. Press F1 (by default) to access the cheats menu. Enjoy :)
### Features
Currently, the mod is packed with these features:
- Equip all weapons
- Invincibility
- Teleport  
And more to be added
