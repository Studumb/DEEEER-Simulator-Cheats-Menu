# DSim Cheats Menu
A cheats menu mod for the game DEEEER Simulator. Locking mods behind paywall is just stupid so I made this.
### Requirements
- [BepInEx]() (Mod loader)
- [BepInEx ConfigManager]() (In-game config menu)
### Installation
Make sure you have finished setting up BepInEx for your game before following these steps. You can find the guide on how to install BepInEx [here]().
1. Run the game after installing BepInEx to initialize all the essential files and folders
2. Download the `.dll` file of the mod [here]()
3. Locate your game folder, in your game folder go to `BepInEx` -> `plugins` and move the `.dll` file into this folder
    - Note: You can locate your game folder from Steam App
4. Press F1 (by default) to access the cheats menu. Enjoy :)
